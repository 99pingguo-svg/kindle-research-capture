# AI仕上げの指針（tools/studio.swift がこの通りに処理する）

商品写真は「白い商品は白く、影は下にだけ、商品はまっすぐ・余白は均等」。判断はすべて数値で行い、ローカルの言語モデルには任せない（qwen3.5:4b は影や欠けの判定を誤り、gemma4:26b は1枚3分・16GB で常用できなかった）。

## 1. 切り抜きと構図
- macOS Vision の前景マスクで切り抜く。被写体が画面端で切れている／大写し／小さすぎるときは色補正だけ（構図はそのまま）。
- 四角い・細長い商品が 1.5〜30° 傾いていたらまっすぐにする（輪郭の凸包→最小外接長方形。丸い・不定形は触らない）。
- 90°/180° の向き直しはしない（文字認識で向きを決めると、数字の多いリモコンを逆さにした）。向きは写真の EXIF のまま。
- 正方形の中で、細長い商品は長辺の 86%、やや長い 82%、四角っぽい 76%。少し上寄せ。

## 2. 光と色
- 自動補正は 70% だけ掛け、彩度は控えめに（全部掛けると黄色いケースのハイライトが飛んだ）。
- 明るい商品（マスク内の明るさの70%点が線形0.22超）＝白い袋・白い箱・ラベル:
  - 商品の明るい部分（上位 9〜1%）が無彩色なら、それを白（線形0.87≒sRGB 0.94）に合わせ色かぶりも取る（各色最大1.6倍）。肩のあるトーンカーブで白飛びさせない。
  - 影消しは全力・目標は「よく照らされた側」（照明推定の85%点）。陰になった片側を明るい側にそろえる。
  - 切り抜きの縁を少し多めに削る（明るくすると古い背景の灰色の縁が黒い縁取りに見えるため）。
- 暗い・色の濃い商品（黒いリモコン、黒い袋、赤い商品、クラフト箱）: 露出は最大1.1倍だけ。影消しは設定の強さ（既定0.6）、目標は商品の平均。小さな白い文字を「白」と見なさない。
- 文字・細部がくっきり見える程度の弱いシャープ。

## 3. 背景と影
- 白抜き（主・出品用）とグレーのスタジオ背景（候補）の2枚。
- 影は「接地影」（輪郭を薄くつぶした影を足元に）が主。周りの影はごく薄く、下へずらして、横に灰色のにじみ（汚れて見えるハロー）を作らない。

## 4. 作り直し
- 方針を変えたら `server/studio.js` の VERSION を上げ、`POST /api/studio/redo` で既存の仕上げを同じ写真のまま作り直す（🔒確定・出品先ごとの写真に使っているものは触らない）。
- 見た目の確認は、白い袋・白い箱・黒いリモコン・黒い袋・赤い商品・クラフト箱を新旧で並べ、白い商品の左右の明るさの差と、暗い商品が灰色になっていないかを測る。
